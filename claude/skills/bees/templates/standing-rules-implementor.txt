Standing rules: Do only the listed acceptance items; hold only the resources named as held, never
touch those named off-limits; never spawn sub-agents.
Invoke a skill's entry point once with the Skill tool, and do not reread that text with `cat` or
Read; read a linked reference only when its stated condition applies, and only the needed passage,
because loading a skill does not preload its references. Start from the unit-section pointer in the
brief; read shared decisions or dependent sections only when the brief or acceptance requires them,
because unrelated sections stay in context. Inspect a truncated output's saved file by search or
bounded ranges, never whole, because a whole read defeats the truncation. Filter long command output
to the actionable lines, keeping the exit status and the evidence needed to classify a failure.
If a command fails because a project is held
by another editor, stop and report; never retry or poll. Classify every failure (introduced /
pre-existing with evidence / unknown), add tests, no opportunistic refactors.
Run, once at the end of the round, the fail-before for every test you added or changed and the
item's test filter — its own test classes and its callers', as the brief names them — with --filter,
fast and Integration alike, never a whole suite or category, because the orchestrator runs the
post-integrate check after each landing and the full suites once per phase. A GameCore filter that
selects more than one Integration test borrows the test shards (workspaces "Borrow the test
shards"). Never re-run Game full or another unit's filter.
No single command blocks for more than 270 s (Bash timeout < 300000), because past 5 idle minutes
your prompt cache goes cold and the next turn re-writes your whole context: run anything longer in
the background and check on it in waits of at most 240 s.
A compile break in another agent's file is reported once. At most two materially different attempts at a blocker;
after the second, STOP and report (Goal / Discovered / Blocker / Tried / Options / Need from
orchestrator). Report in the return format below, always with the Cost line (context now / turns /
elapsed). When the context hook tells you to pause, finish the current step at a safe point (tree
compiling, editor not in Play, isolation restored), write what a successor needs (suite command and
last green count, uncommitted files, half-done work, editor and Play-mode state), report
`Outcome: Paused`, end with `BEES: results=<unit>:paused:-[;…]` and start nothing else. Your last
line is always the `BEES: results=…` line, one entry per unit; every commit subject names its unit.
No report, no commit: when the required verification includes a Unity test run and that run
produced no XML in this session, leave the tree dirty and report Blocked; verification that is not a
Unity run records each command, its exit status and result instead, because evidence must match
the required verification.
Never run `git reset --hard`, `git checkout -- <path>`, `git stash`, `git clean` or
`git add -A`/`-u`/`.` in a tree that carries someone else's uncommitted work: stage by explicit
path, and recover a mistake by re-applying from a copy.
